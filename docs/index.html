    From this map to Blender

    1. Install Lunar Terrain 1.6.0 with Blender’s Install from Disk.
    2. Select a point or location button, then choose Use this location.
    3. In Blender: N → Lunar → Import Location. Open the downloaded JSON.
    4. Click Build / Rebuild Lunar Terrain, then render with F12.

    All nine presets include offline terrain data. The older SOUTH preset retains its nearby legacy origin. The atlas selects the documented MOONBASE regional point.

    What the report represents

    Measured terrain, synthetic detail

    LOLA and LROC DEMs supply broad topography. Rocks, small craters and regolith relief below the DEM grid are procedural analogues. New examples cover a 20 km radius with lunar curvature and progressively coarser geometry farther from the camera.

    Polar targets are regional references

    VIPER uses its published Mons Mouton mission-area center. Nobile Rim 2 and Malapert Massif use NASA Data Book points and historical 2024 candidate status. Connecting Ridge is an early Moon Base mission target region. These points are not final touchdown fixes or safety assessments.

    Appearance and image rights

    Polar presets use an explicitly labeled Apollo Hapke analogue: the regional photometric maps stop at 70° S. Manual Sun settings are illustrative. Mission images stay hosted by their credited providers; their rights are not replaced by the repository’s code license.
